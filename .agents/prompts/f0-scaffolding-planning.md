# Planning Prompt - Phase F0: Scaffolding

## Project Context

Chronicle is a local-first web application for capturing observations of groups in institutions and generating narrative chronicles.

**Current State**:
- Blank repository (only `AGENTS.md` and basic rules initialized).
- Technical source of truth: `docs/stack-and-architecture.md`.

## Objective of Phase F0

Plan the complete scaffolding of the project according to the architecture definition.

## Tasks to Plan

1. **Build/Dev Environment**
   - Setup Vite + React + TypeScript + pnpm.
2. **Styles/UI**
   - Tailwind CSS v4 + shadcn/ui primitives.
3. **Routing**
   - React Router v7.
4. **Forms**
   - React Hook Form + Zod v4.
5. **Persistence**
   - Dexie.js v4.
6. **PWA**
   - vite-plugin-pwa.
7. **Testing**
   - Vitest + React Testing Library (unit), Playwright (E2E).
8. **Lint/Format**
   - ESLint + Prettier.
